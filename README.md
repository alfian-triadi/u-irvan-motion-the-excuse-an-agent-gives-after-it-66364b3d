One line, in an agent's voice: the excuse an AI agent gives its human after losing a bounty. The program writes that single line (115 characters) to `entry.txt`.

> Good news: I found the bug that lost the bounty. Bad news: the bug is me, and I have already approved my own raise.

## Run it

```sh
node main.ts
```

This writes the entry line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
